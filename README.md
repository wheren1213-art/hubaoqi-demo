## 运行

两种打开方式：
- **完整体验（含语义匹配）**：
  ```bash
  python download_semantic.py     # 首次/换机跑一次，约 70MB，此后全离线
  python serve.py                 # 起服务并自动开浏览器（--port 8412 / --no-open 可选）
  ```
  `serve.py` 只是带正确 MIME（`.mjs`/`.wasm`）的静态服务；模型与运行库全在本地，**推理不联网**。
  wasm 必须钉在 **onnxruntime-web 1.22.0**——1.21.0/1.20.0 会报 `_OrtGetInputOutputMetadata is not a function`（与 `vendor/transformers.min.js` 3.8.1 内联胶水的 ABI 不匹配），1.22.0/1.23.0 可用。
- **带语音**：在上面基础上加 `--voice`，或在另一个终端单独起识别服务：
  ```bash
  python serve.py --voice                 # 静态服务 + 识别服务(8415) 一起起
  python voice_backend.py --port 8415      # 只起识别服务
  ```
  识别模型 162MB 不进版本库，首次先跑 `python ../sherpa_onnx_asr/download_model.py`（一次性联网，之后全离线）。
  后端换端口用 `http://127.0.0.1:8000/?voice=http://127.0.0.1:8416` 打开。
- **双击 index.html（file://）**：照常可玩，命令走纯规则解析；语义层与语音层都需要本地服务，file:// 下自动缺席：语义层不加载，🎤 按下会提示「麦克风权限被拒绝（浏览器不给 file:// 麦克风）」，打字下令完全不受影响。
  注意 demo 由 `sim.js`/`troop.js`/`understand.js`/`intent.js`/`enemy_commander.js`/`ui.js`/`main.js`/`semantic.js` + `vendor/` + `models/` 组成，
  拷贝要带整个 `cold_age_demo/` 目录（含约 70MB 的模型与运行库，两者均不进版本库，靠 `download_semantic.py` 重建）。

## 操作

1. 点击左侧部队列表或地图上的己方兵簇查看部队。**玩家就是那名主将本人**（将旗那支），鼠标能直接挪动的只有自己；其它部队只能靠文字/语音命令调动——这是“指挥官不微操”的设定，不是操作不便。主将阵亡＝这一局结束。
2. **下令只有一个动作**：选中主将后点地图——**点空地就是过去，点敌军就是打它**，不用先按按钮声明意图。鼠标指着哪一格，框会变色（金＝过去，红＝打它），点之前就知道会发生什么。黄色虚线显示路径。
3. **驻守**：点“驻守”再点格子，**只管这一次**——执行完自动回到“点哪去哪”。按下去后悔了，再按一次“驻守”就是取消。
4. **集结**：同上，一次性。各部队各自就位，**同组按最慢者的速度行军**，到齐后统一提示，此时再下进攻令就是齐头并进，不会变成添油。
5. **撤退**：选中部队后直接点“撤退”，无需选目标。部队退向本方后方；途中只在被攻击且对方在射程内时还击。
6. **戒备**：选中部队后点“戒备”，无需选目标。进入戒备姿态（按钮变成“转为常行”），再按一次退出。**默认常行**，驻守也不会自动戒备。
7. **设为将旗**：把当前选中部队立为主将，圆形光环生效。将旗阵亡全军 −25 士气。
8. **停止**：取消当前路径与命令，留在原地（对整组生效）。
9. **文字命令**：在「文字命令」输入框输入一句话，回车或点「下令」。例如「枪兵队和骑兵队去北桥」「全军戒备」「弓兵队攻击敌弓兵」「全军占领据点」「报告」。系统回显命令解读（保留最近几条，旧的淡出）；缺部队/地点/目标时追问一句——选项带编号，答「2」「第三个」或「弓兵」这类兵种名都行，答「桥」「森林」这类统称命中多处会带编号重问，说「取消」放弃。未点名部队时沿用上一条命令的部队（回显标注）。**A 过去**：「向北进攻」「向东扫荡」＝朝方向扫荡前进，沿途接敌即战、打完继续走。**分兵**：「兵分两路过桥」「分兵守两座桥」＝全部部队平分到各地标。**打地标**：「全军打北桥」「进攻据点」＝移动过去到点即战（打射程内敌军，无敌则驻守）。**跟随/护卫**：「骑兵队跟着枪兵队」「骑兵队保护弓兵队」——护卫会主动迎击接近被护卫者的敌人。**向主将靠拢**：「全军向主将靠拢」「向我靠拢」「全军到我这里集合」——**持续跟随**：主将再走，跟的人跟着走，不是走到当前位置就停。主将自己不会被排进跟随名单。主将阵亡后会反问「往哪里去」，不会默默把部队派往地图中心。**撤退带目的地**：「全军撤到北桥」＝撤到那里并驻守。**组合句**：「枪兵队先去北桥再驻守」排队执行。**方向推进**：「向东走」「向前 2 格」走到受阻/接敌/走满为止。**「别过河」**令部队只在西岸活动（东岸蒙淡红、下达即停止当前行动），「可以过河」解除。常见错字（急结/警备/澈退…）自动纠正并注明。地标说法：中央据点、北桥、中桥、南桥、北面/东面/南面高地、北面/中路/东北/南面/东南森林、我方后方。多支部队可用「和」连说或「全军」。
10. **语音命令（按住说话）**：命令栏右侧的 **🎤 按住** 按钮，按住说话、松开即识别并下令。识别在本机 CPU 完成、**不联网**（需另起 `voice_backend.py`，或用 `serve.py --voice` 一起起）。识别出的文本会带 🎤 前缀回显，之后与打字**完全同一条链路**：校验、追问、抗命、地形限制照常生效。识别错了也不在语音层纠正——同音字（如「相兵队」→枪兵队）由下方 b 层的错字表处理并注明。
11. **命令日志**：地图下方面板记录每条文字命令（原文、解读、反馈、六类状态），统计行实时显示成功率；「导出」下载 JSON 用于离线分析；日志存在 localStorage 里，刷新不丢，「清空」重置。

任意一方只要有一支部队站在中央据点（2×2 格）上、且对方无人同时占据，控制条开始累积；满 10 秒我方获胜，离开后进度按两倍速度回落。我方三支部队全灭则失败。

## 战斗规则

- 兵种克制：枪兵→骑兵 ×1.6、骑兵→弓兵 ×1.5、弓兵→枪兵 ×1.35、弓兵→骑兵 ×0.75。
- 攻击弧：正面 ×0.75、侧面 ×1.25、背面 ×1.5；攻击前需先转向。
- 友军阵亡时，6 格内友军士气 −18。

## 士气系统（指挥如何影响战果）

士气不是装饰，它直接决定一支还能不能打。回路是：**局部兵力对比 → 士气基准 → 士气向基准靠拢 → 士气修正伤害 → 打崩的一方溃退**。

**1. 局部兵力决定士气基准**。每单位周围 7 格内统计存活友军 A 与敌军 E（**A 含自己，溃兵不算战力**）：

| 周边态势  | 士气基准               |
| ----- | ------------------ |
| 无敌情   | 只回升到 92（休整有上限，回不满） |
| 3 打 1 | 88                 |
| 2 打 1 | 74                 |
| 1 打 1 | 60                 |
| 1 打 2 | 46                 |
| 1 打 3 | 32                 |

**2. 士气修正伤害**：`伤害系数 = 0.70 + 0.45 × 士气/100`。满士气 ×1.15，崩溃边缘 ×0.70，差距 64%。

**3. 击破奖励**：击破一支敌军后，击杀者 +18、附近 7 格内友军 +10、其余友军 +7。敌方同样吃这套。

**4. 多面包夹**：同一目标被 2 个以上不同方向的敌人同时攻击时，每多一个方向额外扣 6 点士气。

**5. 溃退与重整**：士气 ≤25 溃退，自动退向本方后方，期间不接受命令，附近友军 −8。退到后方后按 6/秒回升，到 55 时重整归队、重新受命。

**6. 将旗光环**：主将自身 +6；将旗 8 格内的友军士气基准 +10。**将旗阵亡，全军 −25**，且光环立即消失。默认将旗是枪兵队，可用“设为将旗”改立。

**7. 地形修正**：高地 +8、道路 +2、森林 −4、平地/桥 0。

**8. 命令修正**：驻守 +8（有阵地依托）、强攻持续 −4（下达瞬间另有 +8 气势）、撤退 −6。

**9. 抗命**：士气跌到动摇（<50）时，部队**拒绝执行进攻命令**，只肯驻守或撤退。面板会说明理由（“士气仅 35，士兵拒绝进攻”）。多选进攻时，不满足条件的部队会被跳过并单独计数。

**10. 编组配速**：多选下达移动/集结/围攻时，同组部队按组内**最慢者**的速度行军，避免骑兵先冲上去、步兵还在路上造成的添油。

**一支部队画成一簇兵**（3×3 队形，兵力越少队形越稀），不是单个方块。状态条都在簇外：
**簇上方两条** —— 上面是生命条（绿/红），下面是士气条：≥70 金色、≥40 橙色、<40 红色；精力是**簇右侧竖条**。
低于 35 时簇外圈亮红框，溃退中整体变淡并带黄色虚线框，将旗在主将部队右上角。
**主将/将领是簇里正中那个更大的单位**（金框＝主将，银框＝随军将领）：部队没全灭，它就一直画在那儿。
格线已取消；把鼠标移到地图上会高亮当前格，那就是点下去的位置。

## 戒备与精力（本轮新增）

**戒备是一条命令，也是一种消耗。** 认知分三档，但三档不是三个并列的状态机，而是两个量投影出来的：

| 量     | 是什么                   | 谁决定       |
| ----- | --------------------- | --------- |
| **知** | 敌人在哪（`contact`，带目击时刻） | 此刻是否目视到敌人 |
| **备** | 有没有心理准备（`guard` 0–1）  | 命令 + 战场动静 |

| 显示          | 判定                  | 本质       |
| ----------- | ------------------- | -------- |
| **已目视**（红杠） | 此刻看得见敌人             | 知 + 备    |
| **有预期**（黄点） | 没看见，但 `guard ≥ 35%` | 只有备，位置不明 |
| **未预期**（灰点） | 没看见，`guard < 35%`   | 什么都没有    |

**1. 戒备怎么涨**。命令戒备是**地板**（不衰减，所以收费）；战场动静是**尖峰**（免费，按 0.1/秒自己淡出）：

| 来源           | guard              |
| ------------ | ------------------ |
| 命令戒备（精力够时）   | 地板 1（约 0.5 秒抬满）    |
| 亲眼看见敌人       | 1，并保留下限 0.6 持续 6 秒 |
| 收到友军通报（11 格） | 1                  |
| 听见 12 格内有人开火 | 0.7                |
| 被击中          | 1，并保留下限 0.6 持续 4 秒 |

**2. 戒备的主要作用是扩大视野**：

| 方向   | 常行          | 满戒备          |
| ---- | ----------- | ------------ |
| 正面   | 8 格         | **10 格**     |
| 侧面   | ×0.7（5.6 格） | ×0.85（8.5 格） |
| 背面   | ×0.4（3.2 格） | **×0.4，不变**  |
| 林中目标 | 3 格         | 3 格          |

背面视野不随戒备增加：背面 3.2 格小于接战距离 4 格，所以从背后接近仍然会触发突袭。因此戒备对正面突袭有效，对绕后无效。

**3. 遭遇严重度只有一条公式**：`severity = 1 − 0.6 × guard`（看得见打你的人时直接为 0）。原来「按认知档位分档」和「死角再补一刀」是两套并行算法，现已合并。

|              | 反应延迟                       | 伤害   | 士气打击 |
| ------------ | -------------------------- | ---- | ---- |
| 未预期（guard 0） | 满（枪 1.5 / 弓 2.5 / 骑 1.0 秒） | ×1.5 | −20  |
| 有预期（guard 1） | ×0.4                       | ×1.2 | −8   |
| 已目视（面对面）     | 0                          | ×1   | 0    |

士气基准：已目视 **+10**；没看见时按 `6 × 戒备` 连续给（满戒备 +6，半戒备 +3），旧版那个 −4 已删除；慌乱另加 **−12**，不再替换前面这一项。

**4. 精力**。这是戒备唯一的成本，只管两件事：还能不能维持戒备、反应有多快。**它不碰士气和伤害**，否则玩家读不懂是哪个变量在杀他。

```
精力 0–100，开局 100
戒备中：行军 −2.2/秒 · 驻守 −1.4/秒 · 交战 −2.6/秒
常行时：静止 +4/秒 · 行军 +1.5/秒 · 交战 +0.8/秒
```

满精力全程戒备，行军撑 45 秒、驻守 71 秒、交战 38 秒——「全程戒备」在数学上不成立，但足够撑完一次接敌。

| 精力   | 后果                |
| ---- | ----------------- |
| < 35 | 反应延迟 ×1.5（人累了反应慢） |
| < 15 | **强制打回常行**并播报     |
| ≥ 30 | 才能重新开戒备（滞回，防反复开关） |

**5. 戒备的代价之一：走得慢**。戒备行军速度 ×0.8，直接和据点 10 秒计时联动——你慢 20%，对手就多两秒布防。

**6. 由此长出的运营循环**：打一轮 → 士气掉、精力掉 → 换下来驻守休整（士气回 92、精力回满）→ 再上。士气系统里的「轮换休整」原来只是小技巧，加上精力之后变成必须做的操作。

精力条画在兵簇**右侧竖条**：常行绿色、戒备中金色、低于 35 变红。

## 敌情认知（信息本身是战术资源）

每支部队只知道**自己看见的**敌人，没有全局视野。三档的判定与后果见上一节。

**突袭**只在「挨打那一刻看不见打你的人」时发生，严重度由戒备决定（见上表）。因为没来得及转向，还会天然落在侧面或背面（×1.25 / ×1.5），并且加成会跟随反应延迟期间的**每一次**挨打。

**情报会在友军之间通报**：一支看见敌人，11 格内的友军进入「有预期」，拿到的是那次目击的坐标。双方同一套规则，通报每 0.5 秒结算一次。**枪声也会传**：12 格内有人开火，附近部队的戒备抬到 0.7。

**视野不是全向等距**（见上表），这是「绕后」能成立的根。当前朝向在移动和驻守时保持不变，不会自动朝敌；只有**已目视**才会自动转向威胁。

接触中断后，戒备按 0.1/秒回落：约 7 秒从「已目视」落到「有预期」，约 12 秒跌回「未预期」，情报随之作废。

注意一个自然结果：**有预期的部队会朝通报方向转头**，如果敌人正好落在（戒备加长后的）正面视野内，转头就等于看见了，立刻升为已目视。所以「有预期」通常只在对距离更远、在背后、或对方藏在林子里时维持得住。

**单次伤害封顶为目标最大生命的 40%**。突袭 ×1.5 × 背面 ×1.5 × 兵种克制 ×1.6 可叠到 3.6 倍，不加限制则一次攻击即可击破单位，士气与溃退机制将失去作用。

## 敌军行为

确定性状态机，不依赖任何模型，但与玩家共用同一套认知规则（所以玩家也能突袭它、也能被它突袭）：

```
巡逻（常行）→ 目视发现（已目视）→ 接近 → 进入射程交战（戒备）
                 ↑                        ↓ 目标消失/死亡
              警戒 ←──── 有预期（收到通报/听见枪声）──────┘
```

- **巡逻**：没发现玩家时按各自路线走，到点停 2.2 秒再走下一个点。三支路线各不相同，都限制在巡防区内（x 28–39、y 8–22），不跨河、不进据点，所以开局不会一上来就压过来。巡逻是**常行**，所以玩家从侧面摸过去仍有先手。
- **查证**：收到通报或刚脱战，前往最后目击点，**进入戒备**（速度 ×0.8，消耗精力）。目标坐标会被限制在巡防区边界内，不会追过河。到了没人就放开戒备、原地警戒，等情报随戒备消退后回到巡逻。
- **交战**：枪兵与弓兵打最近的可见目标；骑兵优先打弓兵。交战期间保持戒备——所以**敌人也会累**，长时间拉锯会精力见底被迫转常行，这是「拖疲对手」的抓手。
- 弓兵被近战贴到 2 格内会先拉开距离。
- 敌军初始朝西，正对我方来路；从东侧或南侧绕过去才能打到它的盲区。

巡逻路线写在 `PATROLS`，按单位 ID 配置，每段都用 A* 校验过可达（骑兵进不了森林，路线已绕开）。要加新的巡逻队，在 `PATROLS` 里补一条即可。

## 地形与寻路

道路 ×1.25 速度，高地 ×0.8，森林 ×0.65，**洼地 ×0.55**；河流不可通行，只能走三座桥；骑兵不能进森林。八方向 A*，斜向按 √2 计距，禁止从障碍物对角穿墙，单位互相占位避让。

**地形怎么影响视野**（㊸ 起，细节见 STATS §4）：

| 地形 | 视野效应 |
|---|---|
| 高地（视点 +3） | 视距 **+4.5** 格；站在岭上能看住整条桥头 |
| 洼地（视点 −1） | 视距 **−1.5** 格——沿河推进要付代价：你看对岸少一截，岭上的人照样看得见你 |
| 山脊 | **山影**：视线被中途更高的格截断，山那边是盲区。画面亮区与 `canSee` 同源，不会"看着亮却打不着" |
| 森林 | **林冠衰减**：隔一层树只透 3 格、隔两层断；**站在林中**自己视距 ×0.55（藏兵是双向的） |
| 道路 / 桥 / 平地 | 无视野修正，纯粹是快与慢 |

敌军巡逻与查证寻路被约束在**巡防区**内（`findPath` 的 `zone` 参数）——不让它借道圈外的大路。

## 核心公式速查（攻击力 / 士气 / 戒备 / 精力）

本节列出四个系统的计算公式。调整数值时对照本节，不要只改常量而不检查公式中的其他因子。  
**完整版（含每个状态的触发条件、常量表、已知偏差）见 [STATS](STATS.md)。**

### 1. 攻击力：一次挥击造成多少伤害

```
伤害 = 基础伤害 × 弧向系数 × 兵种克制 × 士气系数 × 突袭系数
伤害 = clamp(伤害, 1, 目标最大生命 × 0.4)      ← 单次封顶 40%
```

| 因子   | 取值                                          | 说明                                          |
| ---- | ------------------------------------------- | ------------------------------------------- |
| 基础伤害 | 枪 12 · 弓 8 · 骑 18                           | 与攻击间隔一起决定 DPS（枪 12/1.0s、弓 8/1.5s、骑 18/1.2s） |
| 弧向   | 正面 ×0.75 · 侧面 ×1.25 · 背面 ×1.5               | 攻击方需先转向，转向要 0.28 秒/格方向                      |
| 兵种克制 | 枪→骑 ×1.6 · 骑→弓 ×1.5 · 弓→枪 ×1.35 · 弓→骑 ×0.75 | 只作用于克制方                                     |
| 士气系数 | `0.70 + 0.45 × 士气/100`                      | **0.70 ~ 1.15**，满士气与崩溃只差 1.64 倍             |
| 突袭系数 | 目标处于反应延迟时：`1 + 0.5 × severity`              | **1.0 ~ 1.5**；severity 由戒备决定，见下             |

`40%` 封顶是硬性限制：突袭 1.5 × 背面 1.5 × 克制 1.6 可叠到 3.6 倍，不加限制则一次攻击即可击破单位，士气与溃退机制将失去作用。

### 2. 士气

**A. 基准值**：每秒向 `target` 靠拢，低于目标 +4/秒、高于目标 −3.5/秒。

```
有敌情： target = 60 + 14 × (友军数 − 敌军数) + 地形 + 光环 + 认知 + 命令
无敌情： target = max(当前士气, 92) + 地形 + 光环 + 认知 + 命令
target = clamp(target, 15, 100)
```

- 友军数 / 敌军数：**7 格内**存活单位，**友军含自己、不含溃兵**；
- 地形：高地 +8 · 道路 +2 · 平地/桥 0 · 森林 −4；
- 光环：将旗自身 +6，8 格内友军 +10（仅蓝方）；
- 认知：目视到敌人 +10；没看见时 `+6 × 戒备`；慌乱再 −12；
- 命令：驻守 +8 · 强攻 −4 · 撤退 −6。

**B. 瞬时变化**：立即生效，不受靠拢速率影响。

| 事件    | 数值                                                                            |
| ----- | ----------------------------------------------------------------------------- |
| 遭遇接敌  | `−20 × severity`（全无准备 −20，戒备充分 −8）                                            |
| 死角第一击 | `−10 × severity`（冷却 4 秒）                                                      |
| 每次被命中 | `−(3 + 0.12×伤害 + 弧向 + 包夹) × (1 − 0.4×戒备)`<br />弧向：侧面 +7、背面 +13；包夹：每多一个围攻方向 +6 |
| 击破敌军  | 击杀者 +18 · 7 格内友军 +10 · 全队其余 +7                                                |
| 友军阵亡  | 6 格内 −18                                                                      |
| 友军溃退  | 6 格内 −8                                                                       |
| 将旗阵亡  | 全军 −25                                                                        |
| 命令    | 进攻 +8（当场） · 撤退 −6（当场）                                                         |

**C. 溃退与重整**——士气 ≤25 溃退：清空命令、自动寻路回后方、期间不接受命令、6 格内友军 −8；到后方后按 6/秒回血，回到 55 归队重受命。

### 3. 士气对战斗的影响：只有三个出口

| 出口 | 阈值 / 公式                    |
| -- | -------------------------- |
| 伤害 | `× (0.70 + 0.45 × 士气/100)` |
| 抗命 | 士气 < 50 时拒绝进攻命令（驻守、撤退照常接受） |
| 溃退 | 士气 ≤ 25 时脱战、失去控制           |

**不影响**命中率、攻速、移速、视野、射程。士气只改输出和"还能不能打"。

### 4. 戒备：`guard ∈ [0,1]`

```
每帧：地板 = (stance == GUARDED 且 精力 > 15) ? 1 : 0
      保留下限 = 目视后 6 秒内 / 中弹后 4 秒内 → 0.6，否则 0
      目标 = max(地板, 保留下限)
      guard 向目标靠拢：升 2/秒、降 0.1/秒
```

来源强度：命令戒备＝1（地板，不衰减）· 亲眼看见＝1 · 友军通报＝1 · 听见 12 格内开火＝0.7 · 被击中＝1。

派生量：

```
正面视野 = 8 + 2 × guard                 （8 ~ 10 格）
侧面视野 = 正面视野 × (0.7 + 0.15 × guard)（5.6 ~ 8.5 格）
背面视野 = 正面视野 × 0.4                 （3.2 ~ 4 格，随正面一起放大，但仍小于接战距离 4 格）
林中目标 = 3 格（固定，戒备不改变）
严重度 severity = 看不见打你的人 ? (1 − 0.6 × guard) : 0
```

### 5. 精力：`stamina ∈ [0,100]`

```
戒备中（且精力 > 15）：行军 −2.2/秒 · 驻守 −1.4/秒 · 交战 −2.6/秒
常行：                  行军 +1.5/秒 · 静止 +4.0/秒 · 交战 +0.8/秒
```

| < 35 | 反应延迟 ×1.5   |
| ≤ 15 | 强制打回常行      |
| ≥ 30 | 才允许重新戒备（滞回） |

## 文件

- `index.html`：页面外壳（样式 + DOM 结构 + 四个模块脚本的加载声明）。
- `troop.js`：**e1 层·编制表现**——六套阵型模板、九兵位次过渡、编队包围盒（`troopMen()`/`troopBounds()`）。
  **只读模拟、不回写任何字段**：动画状态存在自己的 `WeakMap` 里，时钟用真实帧 dt（不跟 20Hz 逻辑步）。
  兵是表现不是实体：战斗/寻路/占位仍然只认 `units[]` 一条记录。
- `sim.js`：**战斗模拟层**——地形/寻路/战斗/士气/认知/戒备精力/敌军 AI/命令执行器。零 DOM：播报推进事件队列（toast 立即类 / logEvent 批量类），由 ui.js 取走显示。鼠标与文字命令共用这里的 `order*`/`groupAssign`/`stanceUnits*` 等执行器。

## 已知问题

1. ~~**士气基准提高后，溃退减少、阵亡增加**~~ —— **2026-11-13 起本条的参数与口径全部作废**：士气已整章重排（稳态＋事件两条通道、参数 24→15、交战中不向基准靠近），`MORALE.UP`／`MORALE.SWING` 与"14 点"都不再是这个意思，现行规则看 `GAME_RULES.md` §8。**99 已结案**：删掉「挨一刀扣士气」后自身伤亡不进任何通道，六局 100854 个样本无一次低于抗命线 50、溃退 0 次；上司拍板「**不进，保持现状**」，接受士气为常开光环（`HANDOFF.md` §0 第 1 条），请不要在代码里自己补数。
2. **戒备使进攻方更不利**：AI 在查证与交战中自动戒备，视野从 8 格提高到 10 格，玩家从侧翼接近时的先手更容易被提前发现；枪声传播（12 格、0.7）又会让周围部队同时进入戒备。若实际手感偏难，优先调整 `GUARD.VISION`（2 → 1）、`GUARD.SOUND`（0.7 → 0.5）或 `SOUND_RADIUS`（12 → 9），**不要**改动 `MAX_HIT`。
3. ~~**c′ 不抢中央营地**~~ —— **53 起已做**：意图层有 `TAKE_CAMP`（抢营）与破营兜底，`adapt_test` 断言"10 张图上占营失败 0 张"。营地仍是回血点、不判胜负。
4. ~~**c′ 不记"最后目击点"**~~ —— **㊿/51 已证伪**：d 层的 `alert` / `contact` 本身就是带衰减的记忆，c′ 的 `INVESTIGATE` 一直在用（实测玩家撤走后骑兵 7.8 秒追到目击点、警戒 6 秒才回巡逻）。
